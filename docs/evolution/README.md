## 指标边界

- 成功表示 PR 交付人审，不表示合并、上线或生产告警消失。
- alert → PR 不是完整故障 MTTR，不含人工审查、发布和生产恢复。
- 每轮 n=3，仅支持观察该样本的链路和规则效果，不外推生产成功率。
- token 是数量，不是金额；两轮没有证明成本或延迟改善。
- 服务快照包含历史 job，回放表仅统计本轮，口径不能混用。
- 本次真实模型审查是独立实验，不能借用旧回放证明新增能力有效。
