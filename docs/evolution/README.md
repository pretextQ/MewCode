## 5. 指标解释与边界

- 回放中的“成功”表示到达 human_review，不代表 PR 已合并、缺陷已上线修复或告警已消失。
- 告警到 PR 的耗时不是完整故障 MTTR；人工审查、发布和生产恢复不包含在其中。
- 两轮各 3 个案例仅用于观察链路与规则影响，不能外推生产成功率。
- Token 是调用量，不是金额；金额必须结合实际模型、价格和计费规则。
- 规则调整提升了该样本的追溯完整性，但不能据此宣称降低延迟或成本。
- 服务指标与回放汇总口径可能不同；长时间运行与大规模样本下需另行验证。
