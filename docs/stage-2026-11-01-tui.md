## 失败修正与取舍

- 初期离线 helper 缺 ProviderConfig 必填参数、继承 CSS_PATH 相对路径落在 tests/helpers，已修正后重跑；不把这两次启动失败计入产品验收。
- 初次 CSS 将带透明度的 text-muted 用于 border 导致解析失败，改为明确边框颜色。工具键盘动作与 Textual DOMNode.action_toggle 重名，类型检查检出后更名。
- 滚动测试首次读取了动画中间位置，等待动画结束后再比较稳定坐标；未放宽“不强拉到底部”的断言。
- Git check-ignore 不接受强制 literal pathspec，也不接受无 stdin 的 -z。改为 NUL 分隔 stdin，仅 diff 使用 literal pathspec；真实临时仓库测试覆盖中英文、方括号、暂存/工作区、忽略项与外部扩展。
- Windows Proactor 管道在 worker 取消/退出竞态下出现未关闭 transport 告警；增加有界读取、终止后排空回收、创建/清理屏蔽重复取消及应用卸载等待。专项使用 `PytestUnraisableExceptionWarning` 作为错误，不屏蔽警告。
- 退出时定时器/分支 worker 可能触碰已卸载控件，增加挂载检查。worker 改用延迟 callable，避免取消尚未启动的 coroutine 产生未 await 警告；显式 Worker[None] 保留 Textual 泛型返回类型。复测 AskUser 发现 Textual 字符串标记解析不兼容旧 `color(99)` 标签，改用 Rich Text 解析并转义动态内容，原回答和计划动作保持不变。
- 计划中的复用安全读取路径采用已有 Git 安全参数约定；没有直接调用服务层 review_diff.git，因为其同步 capture_output 不满足 TUI 的异步和内存上限。本轮将有界实现放在展示包，未引入服务到 TUI 的反向依赖。
- 收尾复核修正模式栏边框占据唯一内容行、矮窗口补全菜单选项被裁剪，以及权限提示空行把拒绝选项挤出可视区的问题。输入尺寸矩阵增加模式栏内容边界和补全最后一项检查；60×18 权限测试断言整个短命令审批组件处于聊天可见边界内，保留原默认选择和允许范围。
- MCP 初始化取消/异常后在 finally 清除连接中标志，保留 manager 供原退出路径关闭，并如实显示连接已停止/失败；没有重新连接或额外授权。召回在当前请求任务内 await，取消不会遗留孤立 side-query；未增加请求或改变提示内容。
- 未修改 NoAltScreenDriver。当前证据支持先修布局；真实主屏 scrollback、缩放重绘和退出恢复必须另作终端烟测。

## 证据与尚待人工检查

`tests/helpers/tui_capture.py` 保存真实 Textual 首屏、普通对话、执行中、权限确认、失败、取消、长历史的四尺寸 SVG 与布局 JSON。A 的原始产物保存在 `phase-a/`，最终含详情的产物保存在 `final/`；另外保留本地字体和 CJK cell-width 修正的预览副本，原始 SVG 不覆盖，预览副本不作为终端烟测证据。它使用替身事件和命令示例，不是实际 pytest 工具执行结果；真实工具/权限语义由相应自动测试验证。SVG 浏览器显示另受 Rich 导出的 CJK textLength/字体限制影响，不将导出字体问题当作真实终端渲染结论。

仍待真实 Windows Terminal 与 Linux 终端人工确认：中英文/全角宽度、长路径/命令、鼠标滚动与选择、resize 重绘、主屏 scrollback、Ctrl+C 退出及终端恢复。两平台 mypy 只是目标类型检查，本地 Windows pytest 和 headless SVG 也不能替代 Linux 运行或人工烟测。纯展示改造未触及共享 Agent、容器或配置传递，因此没有机械重复 Docker 实验。

使用契约见 [TUI 指南](../guides/tui.md)，本计划状态、总入口、演进索引和下次工作入口均已同步。
