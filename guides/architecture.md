# 架构与生命周期

交互式 CLI/TUI 与告警服务共享 `mewcode/agent.py` 执行内核。内核调用提供商适配器，
通过权限检查后调度工具；无头调用与交互调用都保留 thinking 块，并在上下文溢出时压缩重试一次。

项目规则由[共享指令加载器](project-instructions.md)提供，覆盖全局、仓库根至运行目录及本地覆盖；独立代理加载自己的运行目录，fork 继承已有上下文。文件写门禁包含[配置/技能写保护](permission-semantics.md)，拒绝授权可附反馈进入对应 tool_result，不额外创建模型请求。

[进程诊断](diagnostics.md)在 CLI/service/worker、线程、异步及 Textual 异常入口保留堆栈和退出线索，普通日志追加轮转；独立 faulthandler 文件跟随 `MEWCODE_LOG_FILE`，不随普通日志轮转失去描述符。U1–U4 的精确边界见[Agent 契约](agent-runtime.md)。

服务由 `service/runtime.py` 组装 JobStore、WorkerPool 与 ExecutionChain。
HTTP 接入先按仓库策略判定，再在 SQLite 事务内去重建单，随后提交有界消费者队列。
执行链依次完成排查、worktree 创建、基线测试、修复验证、PR 发布和 CI 门禁。
CI 读取对瞬态错误重试并读取所有检查页，认证错误仍会显式失败。

关键通知意图与建单/状态转移同事务写入 SQLite，由独立 Outbox 发送。
通知失败或进程退出后单独补发，不重跑修复；回执和积压可从复盘及指标查询。
首次执行、恢复及人工返工各有执行记录，事件携带 execution ID，修复失败预算仍由原状态机控制。
新任务保存脱敏策略快照，执行与发布入口重验证；仓库路径或分支选择变化升级人工。
详细约定与通知重试端点见[服务可靠性](service-reliability.md)。

`human_review` 表示等待人工评审。带 token 的 decision 端点记录人工合并结论、
修改请求或升级；服务不会执行远端合并。修改请求复用原工作区，重复告警继续归并到待审 PR。
关停先拒绝新接入、关闭 HTTP，再排空消费者并关闭存储。

默认沙箱不可用即拒绝执行；只有显式开启宿主回退才在宿主运行。
Compose 文件由宿主验证后冻结，只允许受限选项，禁止 YAML 别名并限制大小和深度，依赖容器有资源上限。
服务周期清理陈旧工作区时保护未完成与待人工审查的任务，也保留未推送提交或未提交改动。
镜像缓存每仓库保留最近三个 tag，使用中的镜像由容器运行时保护。

长期记忆按分类合并新增条目并原子替换；会话 JSONL 是恢复依据，元数据损坏时可重建。
每个 agent 的大工具结果分别落盘，fork 复制所需引用，彼此压缩不会删除对方的文件。

验证边界：默认测试使用模型和外部服务替身；真实 Docker、模型、GitHub 与 tmux 交互验证需要各自环境。


可选[监督内核](supervision.md)由每个 Agent 持有，默认关闭；事件与提醒总线独立于用户 hooks。交互/headless 请求在裁剪之后注入请求副本，首响应确认送达，再用显式行为 expect 核销。服务/容器沿用同一开关及 JSON 报告。detector 的当前支持范围见监督指南；不增加自动外部动作。

## 定位与证据口径

MewCode 以共享 Agent 内核承载交互开发与告警驱动修复；服务强调权限隔离、原子去重、取消清理、证据与人工审查，不自动合并。历史 PR、演示与回放只能支持相应样本的链路结论。没有真实客户部署、生产在线量、完整故障 MTTR 降幅或节约金额的证据；测试数量不等于业务收益，参考开源实现应说明来源。阶段结果见[验收档案](../docs/acceptance/README.md)，当前未解决边界见[维护待办](../docs/backlog.md)。
