# TUI 使用与数据口径

MewCode 默认采用近黑背景、浅色正文与紫色强调的对话/工作台布局：产品标记和实际版本独立占一栏，下一栏显示项目路径、分支及右侧配置模型；底部是带标签和提示的深色输入卡片，F2 可切换开发详情。MewCode 保留 Python/Textual 界面和共享 Agent。用户消息用 `›`、底色和左边线区分，不单独显示“你 / User / U”标题；助手从 `✦ MewCode` 开始。流式、最终和恢复的正文共用 Markdown 组件，工具输出按纯文本展示。

## 输入、滚动与停止

| 按键 | 行为 |
| --- | --- |
| Enter | 发送；补全菜单打开时使用所选项 |
| Shift+Enter / Ctrl+J | 换行 |
| Tab | 补全；弹窗聚焦时由弹窗处理 |
| 上 / 下 | 输入历史；补全或弹窗聚焦时导航选项 |
| Shift+Tab | 切换原有权限模式；计划/问题控件聚焦时保留原有动作 |
| Ctrl+O | 全局展开/收起工具 |
| Enter / Space（工具聚焦时） | 展开/收起单项或工具组 |
| F2 | 打开/关闭开发详情；审批或提问期间不遮挡控件 |
| Ctrl+End / “返回最新”入口 | 回到最新消息并恢复自动跟随 |
| Esc | 优先处理聚焦弹窗、补全、详情，再停止运行 |
| Ctrl+C | 运行中请求停止；空闲时沿用退出清理流程 |

聊天区独立滚动；离开底部阅读历史后，新文本不会强拉回底部。底部输入区有焦点边框和多行高度上限。少于 28 行时收起快捷键装饰并降低输入高度，给聊天和输入留空间。

底部状态显示已有运行事实和耗时。取消先显示“取消中”，运行收尾后才显示“已停止”；停止不撤销已有修改。正常返回显示“本次运行结束”，不表示任务成功或验证通过。错误保留已有正文与输入草稿，不自动重放工具。运行中发送新普通消息仍沿用原先的打断后发送行为，没有新增消息队列。

## 开发详情

默认专注对话。F2 打开详情后，至少 120 列、24 行时显示侧栏；更窄或更矮时在聊天区域切换到可关闭详情，底部输入区继续可用。F2 或 Esc 返回输入；切换和 resize 不重启 Agent、不增加模型请求，也不重放工具。

“工作区改动”默认不读取文件内容。点击“刷新状态”读取 Git 状态；点击“读取 diff”才读取暂存区和工作区中的已跟踪文件差异。结果明确标注可能包含原有未提交改动，不能认定全部由当前请求生成。未跟踪项只列路径；忽略项及常见凭据路径不进入批量 diff 预览。路径过滤是保守规则，不是内容级密钥检测。文件内容、路径和工具输出不作为 Rich 标记执行。

Git 查询异步执行，每个子命令超时 3 秒、输出最多 48,000 字节；状态最多展示 200 项，暂存区和工作区 diff 共用 48,000 字节预算。超时/截断有可见标记，非 Git 工作区给出空态。禁用 pager、交互提示、fsmonitor、外部 diff、textconv、clean/process filter 和子模块状态/内容查询；查询不修改 Git 索引。刷新按需进行，不随模型 token 查询 Git。

当前任务位于侧栏标签页上方，在文件改动页也可查看。

“执行记录”保留本次打开应用以来最近 100 条工具事件，每条输出最多 12,000 字符；单项默认折叠，展开正文另限制 20 行。显示真实工具名称、目标、错误状态和已保存耗时。没有结果、取消和工具失败分别显示，工具结束不等于测试通过。会话历史恢复时，已保存的工具结果可展开；未保存结果或耗时显示未知，不补造 0 秒结果。

任务区域只显示当前显式请求摘要及已有后台任务数据，无结构化任务/计划时如实显示空态。配置模型、工作目录、Git 分支和 MCP 状态可在详情中查看；顶部显示紧凑信息，长内容省略。token 仅为 Agent 已有的累计输入/输出统计，不代表实时容器额度、剩余额度或费用。验证覆盖保持未知，没有从模型散文或 Bash 成功推断通过数字。

## 离线验收

`uv run python -m tests.helpers.tui_capture` 用临时目录和替身 Agent 驱动真实 Textual 控件，将 SVG 和布局边界保存到忽略的 `docs/evidence/tui-2026-11-01/`，不启动模型、MCP、服务或真实会话。专项为 `uv run pytest tests/test_tui_redesign.py tests/test_tui_details.py tests/test_tui_hardening.py -q --timeout=60`。

headless 控件测试与 SVG 不代替真实 Windows Terminal/Linux 终端的重绘、缩放、滚动和退出恢复人工烟测。实际验收范围与环境限制见[本轮记录](../docs/stage-2026-11-01-tui.md)。

## Windows 终端启动和恢复

Windows 建议从仓库使用 `powershell -NoLogo -NoProfile -File .\scripts\run_tui.ps1` 启动。它在父 PowerShell 外层保存控制台输入/输出模式，子进程返回后复位鼠标、焦点、粘贴、键盘协议和光标，并恢复环境。通常在空闲 TUI 中 Ctrl+C 正常退出；执行中第一次 Ctrl+C 请求停止。

强制终止 TUI 会跳过进程内清理，可能留下鼠标上报，表现为移动鼠标时 PowerShell 出现 `[...;...M`。外层启动器在父 shell 存活时提供异常收尾。已产生的旧字符可以 Ctrl+L 清屏；文件和会话不受清屏影响。
